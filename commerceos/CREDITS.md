# Credits and attribution

MDCart is maintained by its contributors. Individual contributions are
recorded in the repository history.

## Core open-source projects

MDCart is made possible by these projects and their contributors:

- [React](https://react.dev/) and [React DOM](https://react.dev/) — interface runtime (MIT)
- [Vinext](https://github.com/cloudflare/vinext) and [Vite](https://vite.dev/) — application and build runtime (MIT)
- [Cloudflare Workers](https://developers.cloudflare.com/workers/), [D1](https://developers.cloudflare.com/d1/), and [R2](https://developers.cloudflare.com/r2/) — edge runtime, relational storage, and object storage
- [Drizzle ORM](https://orm.drizzle.team/) — typed database access and migrations (Apache-2.0)
- [Tailwind CSS](https://tailwindcss.com/) — styling engine (MIT)
- [Base UI](https://base-ui.com/) and [shadcn/ui](https://ui.shadcn.com/) — accessible UI primitives and component patterns (MIT)
- [Lucide](https://lucide.dev/) — interface icons (ISC; portions derive from Feather Icons under MIT)
- [Recharts](https://recharts.org/) and D3 modules — charts and data visualization (MIT/ISC/BSD)
- [Geist Sans and Geist Mono](https://vercel.com/font) by the Geist Project Authors — bundled typography (SIL Open Font License 1.1)

This list highlights the major projects rather than replacing their license
notices. The complete installed-package inventory and included license texts
are in [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md). The Geist license is
also preserved verbatim in [LICENSES/OFL-1.1-Geist.txt](./LICENSES/OFL-1.1-Geist.txt).
